Política de privacidad de Caudal Editor

Última actualización: 21 de noviembre de 2026.

Caudal Editor es una aplicación de escritorio de Caudal Media. Esta política explica qué datos usa y cómo los protege.

Qué datos usa

  • Datos de las cuentas de YouTube que el usuario conecta: nombre del canal, lista de videos y estadísticas.
  • Los videos, títulos y descripciones que el usuario decide subir.
  • Un permiso de acceso (token) que Google entrega cuando el usuario autoriza la aplicación.

Cómo los usa

Solo para subir los videos que el usuario elige, mostrarle las estadísticas de sus canales y buscar videos públicos. No se usan para publicidad ni se venden.

Dónde se guardan

Todo se guarda únicamente en el computador del usuario. Caudal Editor no tiene servidores propios y no envía estos datos a terceros, salvo a Google (YouTube) para cumplir lo que el usuario pide.

Servicios de Google

Caudal Editor usa los Servicios API de YouTube. Al usarlo, el usuario acepta los Términos de servicio de YouTube y la Política de privacidad de Google. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo quitar el acceso

El usuario puede retirar el permiso cuando quiera en myaccount.google.com/permissions y borrar los archivos de la aplicación de su computador.
